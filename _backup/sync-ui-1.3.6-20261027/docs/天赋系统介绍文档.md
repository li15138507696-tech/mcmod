# 天赋附属（tianfu）介绍文档

> 版本：tianfu-1.3.5 ｜ 运行环境：Minecraft 1.21.1 · NeoForge ｜ 前置：蛊真人本体模组（guzhenren）

> 1.3.5 修复内容见 [本次修复记录](2026-10-26-bugfix.md)。

## 一、模组简介

本附属为蛊真人本体提供一套**觅长生式自由购买天赋系统**：以**希望蛊**开窍后选择开局难度领取「自由点」，按 K 打开天赋界面，用点数随意购买体质、机缘与词条。点一下立即生效，无抽卡、无随机候选、无锁定重掷。

- 无新增物品、模型、贴图、数据包资源，全部功能通过 Mixin、事件监听与自绘界面实现
- 不修改本体核心逻辑（KE1/KE2/KE3 命脉不动），十绝体等本体天赋购买后由本体原生生效
- 玩家数据存储在玩家自有 PersistentData 中，**永久保留**
- **希望蛊是唯一开窍开关**：右键希望蛊即开窍并弹出本界面；本体原有的随机空窍资质（kongqiao 1–10 随机）与抽卡式资质面板已被整体取消，开窍后空窍保持「无资质」，基础真元回复靠购买机缘恢复

## 二、快速上手

1. **开窍**：右键使用**希望蛊**——本附属天赋系统的唯一开窍开关。本体原有的空窍资质 1–10 随机抽取已取消，开窍后空窍保持「无资质」（没有基础真元回复，购买机缘后写入对应档位恢复），并自动弹出本界面。
2. **选难度**：开窍收尾时若尚未选择开局难度，会自动弹出天赋界面，四档难度任选其一——**选定后永久固定**。
3. **买天赋**：随时按 **K** 打开天赋界面，点击条目即可购买，购买立即生效，界面原地刷新不重置。
4. **最终确认（本世锁定）**：选好难度与天赋后，点界面右上角 **「最终确认」**，二次确认后本世的购买 / 撤销 / 难度**全部冻结**（界面转只读，撤销按钮消失）。只有**寿元耗尽转世**（开启新一轮）才能重新选择。
5. 点数花完为止；部分负分词条购买后还会**返还 2 点**。
6. **未开窍时按 K** 不会打开界面，只提示「需以希望蛊开窍，方可踏上仙途」。
7. **转世（寿元耗尽）**：天赋点、已购、难度、最终确认全部清零，开窍状态一并重置——**转世不会自动弹界面**；需**重新使用希望蛊开窍**才会进入新一轮（重新选难度、重新购买）。

## 五、界面操作

- **K 键**打开合一界面：查看 + 购买同屏（**未以希望蛊开窍前会被拦截，只提示需以希望蛊开窍**）
- **分类标签页**：凡体 / 资质（十绝体 + 机缘合并为一页）/ 词条 / 已购，四个标签各自记忆滚动位置；词条标签下还有品质二级筛选（全部/极/神/天/地/玄/黄/负）
- 顶栏显示当前空窍档位、开局难度、自由点余额
- 点击条目**立即购买**（服务端权威校验，成功后**原地刷新**：界面不重建、滚动位置与当前标签保持不变）
- **体质限购一个**：已拥有体质（含天然十绝体）时体质条目灰显，服务端二次拦截
- **最终确认（本世锁定）**：已选开局难度后，界面右上角出现「最终确认」按钮；**必须至少拥有 1 个「资质」（机缘 或 十绝体，二者取其一）**才可点击（否则按钮置灰、旁注「需先选 1 个资质（机缘 / 十绝体）」，服务端同样兜底拦截）；二次确认后本世的购买 / 撤销 / 难度全部冻结（界面转只读，行内撤销按钮消失，服务端二次拦截），仅**寿元耗尽转世**后解除并可在新一轮重新选择
- **效果在最终确认时才生效**：购买只把条目写入「已购」，确认前不加任何数值（真元／念头回复、属性、战斗乘区、上限类、飞行、粒子均不生效）；点下最终确认的那一刻统一结算一次。旧存档（本版本之前已购买并落地过）自动识别为「已落地」，不会重复叠乘
- **体质自带流派增幅**：部分体质会额外挂上本体同名的流派增益 buff，**无限时长常驻**，撤销体质／转世时回收。只覆盖本体**确有**对应增益 buff 的流派：剑道（剑道伤害增幅）、金道（镀金）、气道（气道蛊虫威力增幅）、律道（律道增幅）、炎道／雷道（炎煌雷泽体按随机结果）。buff 等级取本体同款 1 级（即 +1%），**只改时长不改数值**。其余流派本体没有对应 buff，不硬造；宙道 buff「宙侵」本体是负面效果（倒扣时间加速），故不挂
- 不可购买（点数不足、已购、体质限购等）条目灰显
- 滚轮滚动 + 拖动右侧滚动条
- 按 F6 可显示命中区调试框

### 命运由天（随机生成）· 1.2.35 新增

开局除了「自己买」，还可以让系统摇一份：

1. 在**选难度那一屏**右侧点亮 **「命运由天 · 随机生成」**（点亮后标题变成「命运由天 · 选择难度」）。
2. 点任一难度行 → 弹「确认命运由天？」→ 确认后服务端按该档点数生成一份配置。
3. 界面转为**只读抽签预览**：抽到的每一条都列出来，底部显示净耗点数与剩余重摇次数。
4. 满意点 **「接受此命 · 锁定本世」**（落库 + 结算 + 立即锁定，等价于手动「最终确认」）；
   不满意点 **「再摇一次」**，**每世共 3 次**（服务端记账，重连 / 重登不重置，用尽后按钮置灰）。

规则：

- **必含 1 个资质**（十绝体或机缘）。最终确认本来就要求至少 1 个，随机不保证的话摇完会直接卡死。
- **资质分两层抽**：
  - **第一层**：候选 = `{十绝体, 甲, 乙, 丙, 丁}`，每个候选一个槽位、**等概率**。点数够时五等分（各 20%）。
  - **第二层**：第一层抽中「十绝体」这个类别后，再在 **11 个十绝体**里抽一次（1/11）；抽中某个机缘档则直接取该档（每档只有一条）。
  - 买不起的候选**先剔除再归一化**：24 / 16 点档 5 个槽位各 20%；12 点档剩 3 个（乙 / 丙 / 丁）各 33.3%；8 点档剩 2 个（丙 / 丁）各 50%。
- 凡体：尚未有体质、点数 ≥3 时按 70% 概率摇一个（体质唯一；抽到十绝体则不再摇凡体）。
- 剩余点数**贪心花光**：按成本加权抽词条（越便宜权重越高），负分项会返还点数继续买；上限 64 轮防死循环。
- 随机结果**不可手动增删**，接受即本世锁定；已选难度的存档**不能再摇**（随机与自定义是二选一的两条路）。
- 转世（寿元耗尽）时摇签次数与待定结果一并清零。

> 实测分布（1000 次/档）：24 点档平均 31.1 条、十绝体 20.2%、凡体 56.4%；16 点档 27.7 条、19.4%、42.6%；
> 12 点档 27.5 条、十绝体 0%；8 点档 26.2 条、十绝体 0%。
> 即结果多半是「一个机缘/十绝体 + 一堆 1–2 点小词条」，十绝体不再常见。

## 六、数值设计要点

- 体质对应的道痕**成对写入**本体 `daohen_*` 与 `liupai_*` 字段，本体显示与判定原生读取
- 战斗乘区封顶保护：暴击率 ≤50%、吸血 ≤15%、闪避 ≤60%、减伤 ≤50%
- PVP 计算顺序固定：先受击方减伤/闪避，再攻击方伤害倍率
- 反伤带递归防护，不会出现反伤死循环

## 七、安装

1. 确认已安装蛊真人本体模组
2. 将 `tianfu-1.3.1.jar` 放入 `.minecraft/versions/<版本目录>/mods/`
3. 启动游戏即可；进服后**用希望蛊开窍**即进入天赋流程

> 兼容性提示：FTB Quests 部分版本存在首次启动资源重载时的崩溃 bug（与本附属无关），进入主菜单后按 F3+T 重新加载资源即可。

**新增的原始语**（都在 TianfuTalents.Op 里）：

- ON_HIT_EFFECT —— 出伤时给目标上药水效果（毒 / 凋零 / 缓慢 / 虚弱 / 致盲）
- ADAPTIVE —— 按伤害类型 msgId 记层数，同类伤害递减（内存表，最多记 16 种类型）
- COUNTER —— 受击后 N tick 内出伤倍率加成
- UNDYING —— 致命伤害改为留 1 血 + 回血，带冷却
- AURA —— 每 60 tick 对半径内 Enemy 结算魔法伤害
- 另有 REDUCTION_PHYS / REDUCTION_MAGIC / FALL_REDUCE 三个细分减伤原语

**口径说明（描述与实现一致）**：

- 摄魂 / 破魔按「伤害是否吃护甲」分流：吃护甲（近战、弹射物、爆炸）走摄魂，穿护甲（魔法、药水、虚空）走破魔，两者互斥不叠加
- 月步是摔落伤害乘区（IS_FALL 标签），不是安全坠落高度
- 适应的层数按 DamageSource.getMsgId() 记忆，细到 minecraft:mob_attack / minecraft:magic 这一级
- 恶意组在「已购」页同样列出；已购买后卸载恶意，条目仍可撤销（走 byIdIncludingUnavailable，不会白扣点）
- **不死之身的冷却写进玩家 PersistentData（按世界游戏时间计）**，重登、换维度都不会重置；适应层数与反击窗口存在内存里，下线即清（都只是短时状态，无残留）
- **杀意凛然只打敌对生物（Enemy）**，PVP 不生效
