# 宙蚀（宙侵）机制解析

## 术语纠正

用户说的「宙蚀」「某烛效果」，本体里真实叫法是 **宙侵**，对应效果
`guzhenren:zhoudaobuff`（lang: `effect.guzhenren.zhoudaobuff = 宙侵`）。
「烛」字出现在 `瞬现烛蛊` / `火光烛天蛊`，与宙道侵蚀无关。

## 三个相关效果（别混）

| 注册名 | 中文 | 类别 | 作用 |
|---|---|---|---|
| `zhoudaobuff` | **宙侵** | NEUTRAL | 侵蚀标记本身，每 tick 发粒子 |
| `zhoudaobuff_2` | 覆辙 | NEUTRAL | 伤害结算时把 amplifier 直接加进伤害 |
| `zhoudaoshijianbuff` | 冷却 | — | 延长宙侵时长 |
| `zhoudaoshijianbaifenbibuff` | 冷却 | — | 倍率延长宙侵时长 |

## 施加流程（以 `ShizhuotanshewuDanSheWuJiZhongShiTiShiProcedure` 为例）

命中目标时：

1. **若目标已有宙侵** → 立即结算一次伤害：
   ```
   ShangHaiLiuCheng1Procedure.execute(level, attacker, target,
       attacker.dahen_zhoudao,                                    // 道痕
       target.zhoudao_shijian_baifenbi,                            // 倍率
       target 已有宙侵时长 × 0.1,                                   // 已侵蚀时长折算
       "ZhouDao")
   ```
   即「按已侵蚀时长结算伤害」——这是宙道爆发的核心。

2. **然后重新施加宙侵**（覆盖）：
   ```
   duration = (200 × zhoudao_shijian_baifenbi
               × (1 + zhoudaoshijianbaifenbibuff等级)
               + zhoudao_shijian
               + zhoudaoshijianbuff等级 × 10)
   amplifier = 传入的 amp
   ambient = false, visible = true
   ```
   基准 **200 tick = 10 秒**。

3. 施加时播放 `ZHOUDAOLIZI_2` 粒子（count 100，扩散 2.0）+ `guzhenren:guchong_cuidong_4` 音效。

## 伤害加成（`ShangHaiLiuCheng1Procedure`）

流派标记为 `"ZhouDao"` 或 `"ZhouDao_ZhenShang"` 时：

```
damage += target.getEffect(ZHOUDAOBUFF_2).getAmplifier()   // 覆辙层数直接加伤害
```

注意用的是 **`ZHOUDAOBUFF_2`（覆辙）**，不是宙侵本身。

## 持续与结束

- `ZhoudaobuffMobEffect.shouldApplyEffectTickThisTick` **恒返回 true** → 每 tick 都执行。
- 每 tick 调用 `ZhoudaobuffXiaoGuoChiXuShiMeiKeFaShengProcedure` → 只发粒子（`sendParticles` 0.5 扩散）。
- `onEffectStarted` → `zhoudao_shijian_baifenbi -= amp × 0.1`（侵蚀加深）
- `onMobRemoved(KILLED)` → `zhoudao_shijian_baifenbi += amp × 0.1`（死亡回吐）

## 关键字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `zhoudao_shijian` | double | 宙侵时长加值（tick） |
| `zhoudao_shijian_baifenbi` | double | 宙侵时长倍率，**默认 1.0** |
| `dahen_zhoudao` | double | 宙道道痕，伤害基数 |
| `liupai_zhoudao` | double | 宙道熟练度 |

## 对我们模组的意义

`zhoudaobuff` 是 **NEUTRAL** 而非 HARMFUL——这点很重要：
它可以挂在玩家身上而不被当作负面效果清除，但也不吃「清除负面」的保护。
之前记录「宙道 `zhoudaobuff` 是 DEBUFF」不够准确：它是中性侵蚀标记。
