# 天赋附属（tianfu）介绍文档

> 版本：tianfu-1.3.8 ｜ 运行环境：Minecraft 1.21.1 · NeoForge ｜ 前置：蛊真人本体模组（guzhenren）

> 1.3.8：开局选择改为可返回、可跳过可选阶段的向导；随机候选需主动接受，之后仍进入总复核并最终确认。

> 1.3.6 修复内容见 [本次修复记录](2026-10-27-bugfix.md)。

## 一、模组简介

本附属为蛊真人本体提供一套**自由点天赋系统**：以**希望蛊**开窍后进入开局向导，选择难度领取自由点，再手动购买或生成随机候选。选择即时保存，命格效果在总复核后最终确认时统一结算。按 K 可重新打开向导。

- 无新增物品、模型、贴图、数据包资源，全部功能通过 Mixin、事件监听与自绘界面实现
- 不修改本体核心逻辑（KE1/KE2/KE3 命脉不动），十绝体等本体天赋购买后由本体原生生效
- 玩家数据存储在玩家自有 PersistentData 中，**永久保留**
- **希望蛊是唯一开窍开关**：右键希望蛊即开窍并弹出本界面；本体原有的随机空窍资质（kongqiao 1–10 随机）与抽卡式资质面板已被整体取消，开窍后空窍保持「无资质」，基础真元回复靠购买机缘恢复

## 二、快速上手

1. **开窍**：右键使用**希望蛊**——本附属天赋系统的唯一开窍开关。本体原有的空窍资质 1–10 随机抽取已取消，开窍后空窍保持「无资质」（没有基础真元回复，购买机缘后写入对应档位恢复），并自动弹出本界面。
2. **选难度**：开窍收尾时若尚未选择开局难度，会自动弹出天赋界面，四档难度任选其一——**选定后永久固定**。
3. **选择命格**：按向导逐步选择难度、出身、资质根基、流派、体质、心智和气运；可返回修改并跳过非必选阶段。也可生成随机候选，主动接受后加入已选。
4. **总复核与最终确认**：核对难度、出身、已购命格、点数和未接受候选；可返回修改。二次确认后本世购买 / 撤销 / 难度**全部冻结**（界面只读）。只有**寿元耗尽转世**（开启新一轮）才能重新选择。
5. 点数花完为止；部分负分词条购买后还会**返还 2 点**。
6. **未开窍时按 K** 不会打开界面，只提示「需以希望蛊开窍，方可踏上仙途」。
7. **转世（寿元耗尽）**：天赋点、已购、难度、最终确认全部清零，开窍状态一并重置——**转世不会自动弹界面**；需**重新使用希望蛊开窍**才会进入新一轮（重新选难度、重新购买）。

## 五、界面操作

- **开局向导**：难度 → 出身 → 资质根基 → 流派 → 体质 → 心智 → 气运 → 总复核。
- **返回与跳过**：难度和总复核必经；出身及可选命格分类可跳过。资质根基只有在本体资质满足，或已有合规十绝体/机缘时才能跳过。
- **分类选购**：保留搜索、已选筛选、条目详情、点数余额与购买/撤销二次确认；每项交易仍由服务端校验并即时保存。
- **随机候选**：在资质、流派、体质、心智或气运阶段生成；每世最多三次。查看候选后可主动接受，接受后追加到已选，不替换原有选择；未接受候选不计入结算。
- **总复核**：汇总难度、出身、余额、负面补点、已选命格及未接受候选。点击「最终确认」并二次确认后统一结算、锁定本世。
- **关闭与重开**：关闭不会自动确认；本次游戏会话内再次打开会沿用当前阶段。重登后按已保存状态定位到难度、资质根基或总复核。
- **只读状态**：最终确认后只能查看总结，不能购买、撤销、生成或接受候选。
- **快捷键与浏览**：K 键打开（仅开窍后）；滚轮滚动，Ctrl+F 搜索，F6 显示命中区调试框。

### 命运由天（随机候选）

在天赋选择阶段可以让系统根据当前剩余自由点和已选命格生成候选；每世最多成功生成三次。候选先保存在待定区，不会立即购买或结算。再次摇取会替换当前待定候选。

- 生成候选后可查看完整条目和价格；点击「接受候选」后由服务端整批复核并追加到已选，不会替换手动选择。
- 接受候选后仍需回到总复核并进行最终确认；只有最终确认后才结算并锁定本世。
- 未接受的候选不会购买，也不会计入最终结算；余额或互斥校验失败时，候选会保留供玩家处理。
- 随机次数和待定候选由服务端保存，重登不会重置；转世后重新开始。

## 六、数值设计要点

- 体质对应的道痕**成对写入**本体 `daohen_*` 与 `liupai_*` 字段，本体显示与判定原生读取
- 战斗乘区封顶保护：暴击率 ≤50%、吸血 ≤15%、闪避 ≤60%、减伤 ≤50%
- PVP 计算顺序固定：先受击方减伤/闪避，再攻击方伤害倍率
- 反伤带递归防护，不会出现反伤死循环

## 七、安装

1. 确认已安装蛊真人本体模组
2. 将 `tianfu-1.3.8.jar` 放入 `.minecraft/versions/<版本目录>/mods/`
3. 启动游戏即可；进服后**用希望蛊开窍**即进入天赋流程

> 兼容性提示：FTB Quests 部分版本存在首次启动资源重载时的崩溃 bug（与本附属无关），进入主菜单后按 F3+T 重新加载资源即可。

- COUNTER —— 受击后 N tick 内出伤倍率加成
- UNDYING —— 致命伤害改为留 1 血 + 回血，带冷却
- AURA —— 每 60 tick 对半径内 Enemy 结算魔法伤害
- 另有 REDUCTION_PHYS / REDUCTION_MAGIC / FALL_REDUCE 三个细分减伤原语

**口径说明（描述与实现一致）**：

- 摄魂 / 破魔按「伤害是否吃护甲」分流：吃护甲（近战、弹射物、爆炸）走摄魂，穿护甲（魔法、药水、虚空）走破魔，两者互斥不叠加
- 月步是摔落伤害乘区（IS_FALL 标签），不是安全坠落高度
- 适应的层数按 DamageSource.getMsgId() 记忆，细到 minecraft:mob_attack / minecraft:magic 这一级
- 恶意组在「已购」页同样列出；已购买后卸载恶意，条目仍可撤销（走 byIdIncludingUnavailable，不会白扣点）
- **不死之身的冷却写进玩家 PersistentData（按世界游戏时间计）**，重登、换维度都不会重置；适应层数与反击窗口存在内存里，下线即清（都只是短时状态，无残留）
- **杀意凛然只打敌对生物（Enemy）**，PVP 不生效
