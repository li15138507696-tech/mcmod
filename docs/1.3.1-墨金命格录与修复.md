# 天命1.3.1：墨金命格录与修复

七页仍为难度、出身、资质、流派、体质、心智、气运。宽屏采用左目录、中列表、右详情；小窗切成列表与详情两种视图，以“返回”或Esc回到列表。全程使用原生逻辑像素，不整体缩放界面。

查找框支持名称、品质与效果文字，各页保留搜索和滚动。已选筛选方便核对配置；完整效果和代价在详情中独立滚动，最终确认弹窗列出全部已购及出身，长内容可滚动读完。所有交易先弹窗确认，提交期间防止重复点击。

已修复的功能问题：

- 手动最终确认没有进入真正结算与锁定流程；已恢复基础体质、一次性词条及出身结算。先预检，成功后才锁定；失败恢复本体字段和天赋记录。
- 自愈路径提前标记“已结算”，导致后续结算被自身拦住。现在通过统一入口补结算，历史即时加成跳过重复发放。
- 随机请求漏了开窍、难度、确认锁和次数限制。现在成功生成非空可行候选才消耗一次机会，最多三次；无解保留原候选。
- 接受随机失败也清掉候选。现在失败保留，成功追加已选；仍须独立点击最终确认。
- 难度选择未推进权威版本，导致客户端收到点数后又被旧缓存盖回。现在通过统一事务提交难度和基础点，并推进版本。
- 跨连接及玩家替换没有清空快照缓存。现在清理旧生命周期缓存，拦住清理前已排队的旧状态。
- 刷新接口忽略传入快照、按钮亮起条件与点击条件不一致、十绝体显示虚假的撤销操作、预算不足和24补点上限缺少提示。现在按同一套只读经济规则展示原因和预计余额。
- 恢复基础效果时避免与适配层重复执行重度负面；命烛残尽只扣400寿元，重复确认不再扣。

说明：扩展词条本就会合并进目录，本轮没有把它们描述为“全部无法购买”；购买效果依然由服务端核对。未改各项目录价格、24点上限或本体炼蛊完成判定。
