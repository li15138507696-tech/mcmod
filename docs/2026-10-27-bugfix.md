# tianfu 1.3.6 修复记录

日期：2026-10-27

## 资质选择界面一直显示“等待服务器同步”

新版界面启用和提交资质选择依赖 V2 权威快照，但开窍自动弹窗与 `/tianfu open` 只发送了旧版状态包。旧包会创建界面，却不包含 V2 快照；界面因此一直保持不可操作状态。

修复内容：

- 统一由 `openSelection` 先迁移旧数据，再发送 V2 快照和旧版界面状态。
- V2 快照先于旧版状态抵达，避免界面先创建后等待。
- 请求失败时停止用旧版状态伪装同步成功，改为向玩家显示失败提示并保留服务端日志。

验证范围：Java 21 全量编译、JAR 结构与版本一致性、资源文本/BOM 检查。未启动 Minecraft 实例，未进行游戏内实测。
