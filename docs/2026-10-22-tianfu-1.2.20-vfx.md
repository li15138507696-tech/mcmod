# tianfu v1.2.20 — 剑势环 与 火焰环绕

> 承接 v1.2.19。这一版**只改特效**，不动任何玩法逻辑。

## 一、先说清楚「特效」和「效果」的区别

上一版（v1.2.19）我做的是**效果**：19 个「X烛」MobEffect，命中挂标记、再命中结算伤害。

你说「换个特效」之后我才明白，你要的是**特效**——**看得见的东西**：

> 「想剑道就有剑的虚影，火就有火焰环绕」

tianfu 本来就有特效系统 `TianfuVfx.java`（600 行），这一版是在它上面加两种新形态。

## 二、新增两种形态

### `SWORD` 剑势环

给**断岳剑心体**（tizhi=25）。

| 参数 | 值 | 为什么 |
|---|---|---|
| 粒子 | `tianfu_jianqi`（剑气，6 帧弧形刃光动画） | 本来就是剑气 |
| 密度 | **20** / tick | 原来 `RING` 是 3；要「密集到能看出剑势」必须大幅提高 |
| 转速 | 每 tick 转 1/30 圈（一圈 1.5 秒） | 比原 `ORBIT`（2 秒）更快，更凌厉 |
| 层数 | **2 层**（腰 0.55 / 胸 1.05） | 单层会所有剑气挤在一个平面，看着像盘子 |
| 半径 | 0.55 ~ 0.80 呼吸 | 「剑阵收缩/扩张」的观感 |
| 速度 | **切向**（沿圆周切线） | **这是关键**：只有切向速度才能拉出剑痕；否则密集粒子只会糊成一团雾 |

### `FLAME` 火焰环绕

给**炎煌雷泽体**（tizhi=5，十绝体，原来没有任何特效）。

| 参数 | 值 | 为什么 |
|---|---|---|
| 粒子 | `tianfu_sharen_yan`（杀焰，火苗动画） | 现成的火焰粒子，你说用现成的 |
| 密度 | **14** / tick | 螺旋要连续 |
| 高度 | 0.05 → **1.75** 格 | 玩家高 1.8 格，必须覆盖全身 |
| 圈数 | **2 圈** | 1.5 圈火线太疏 |
| 半径 | 0.70 → 1.10 递增 | 越高越散开，像真火 |

## 三、模拟图暴露并修掉的一个真缺陷

**火焰原本只烧到腰，根本没「环绕」全身。**

第一版 `h = t * 1.25`（t 从 0 到 1），最高只到 1.25 格，而玩家高 1.8 格。侧视图一眼就看出来：火焰全堆在腰部以下，像个火盆，不是「环绕」。

修复：`h = 0.05 + t * 1.70`，覆盖 0.05 → 1.75 格；同时把圈数从 1.5 提到 2.0，让火线更密。

**为什么这个缺陷静态代码看不出来**：`h = t * 1.25` 语法完全正确，也没有任何常量明显「不对」——只有把坐标真算出来画成侧视图，才能看到「火焰高度不到人的胸口」。

## 四、性能：密集形态不参与错峰

原系统的错峰机制：18 个体质分散到 12 个 phase，**每 tick 只播一个**，每次 3 个粒子。

`SWORD`（20）和 `FLAME`（14）如果也走错峰，就会**每 12 tick 才出现一批**，视觉上断成一段一段，完全看不出环绕。

所以这两个形态**每 tick 都播**：

| 形态 | 频率 | 单次粒子 | 每 tick 平均 |
|---|---|---|---|
| `RING` / `COLUMN` / `ORBIT` | 每 12 tick | 3 | 0.25 |
| `SWORD` | **每 tick** | 20 | **20** |
| `FLAME` | **每 tick** | 14 | **14** |

代价是剑修玩家每 tick 1 次 `sendParticles`（20 粒子），约为普通形态的 **80 倍**。

**为什么可接受**：单次 20 粒子在服务端是常量级开销（`ServerLevel.sendParticles` 内部是一次 AABB 查询 + 对范围内玩家发包）。20 粒子 × 1 次/tick = 20 粒子/tick，对比原版「火焰粒子雨」之类的场景仍在同一量级。

**但这是个需要盯着的数字**：如果将来把密度加到 50+，或同时有多个剑修在同一个区块，需要重新评估。代码注释里已写明这条边界。

## 七、诚实说明

**游戏内未实测。** 结论来自：编译通过、离线可视化渲染、扇区覆盖断言、jar 验证。

需要你进游戏确认的：

1. **20 粒子/tick 的观感**——可能偏浓，也可能还不够。这是主观的，只能实机看。若太浓，把 `SWORD` 密度从 20 降到 12；若不够，提到 30（但要重新评估性能）。
2. **粒子贴图**——模拟图里剑气是圆点，实际 `tianfu_jianqi.png` 是 6 帧弧形刃光（32×192）。实机上每颗粒子是一个小弧，**看起来会比模拟图更像剑**，但也可能因为弧的方向固定而显得乱。
3. **火焰用的是杀焰粒子**（`tianfu_sharen_yan`，血红火苗），不是橙色火焰。如果你要橙色，需要新建粒子贴图。
4. **`FLAME` 只给了炎煌雷泽体**。20 个凡体里没有火系，所以其他体质没有火焰。

### 上一版（1.2.19）的 19 支烛还在

你说「换个特效」是**换特效**，不是撤掉效果。所以 v1.2.19 的 19 个「X烛」MobEffect 仍在，这一版只是**额外**加了两种视觉形态。
