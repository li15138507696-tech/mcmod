# 1.4.14：本体 9.8 适配的常用路径优化

本次在 1.4.13 的 9.8 适配上减少重复计算和临时对象，不改词条数值、购买规则、本体恢复节拍或存档格式。按用户要求，本次没有启动 Minecraft 客户端或服务端。

## 修改

- 词条汇总直接从 ID 索引读取效果，并按索引遍历不可变效果列表，去掉中间天赋列表及每个词条的效果迭代器。保留原有 ID 顺序和浮点相加顺序；未知旧 ID 仍跳过，已购但当前不可购买的 ID 仍能识别。
- 每 tick 硬代价维护复用该 tick 已读取的有效词条，不再为此重新解析全部成交账、出身、补点与完整快照。三种硬代价全部未选时，直接跳过本体附件读取。原有 `VersionAdapter.maintain` 和 `TianfuEffects.maintainV2` 接口保留。
- 属性维护仍检查实际属性实例，属性金额和运算方式没变时跳过重复构造与替换；本体或其他附属移除修正后，后续维护仍可补回，不使用玩家级属性缓存。
- 本体真元/念头赋值不是有限正增量时，提前返回原生值；清除或无效冷却也提前返回，避免为这些路径读取天赋。普通正向回复、修炼和突破公式保持 1.4.13 的实现。
- 旧词条查询改为 ID 索引查找；已购 ID 的识别不再为了判定存在性构造展示对象。

## 本地验证

完整主源码按指定 9.8 本体编译成功，产出 118 个类。9 个 mixin 均在包中，元数据版本为 1.4.14，保持本体 9.8 的机制指纹核验。

- 2,333 项目录查询和随机组合汇总检查通过，含未知旧 ID、历史条目和原始浮点累加顺序。
- 101 项硬代价行为检查通过。使用真实适配器源码配合本地字段/存储夹具，覆盖三种代价的全部组合、旧 `maintain` 接口、气运归零、资质锁定、寿元上限下移、重复维护不置脏及缺失历史锁值；没有创建真实 Minecraft 玩家。
- 20 项结算边界检查、10,034 项进度/恢复/概率/冷却逻辑断言通过。
- 原有无服务端回归 157 项通过，覆盖温养、容差、旧映射与购买规则；其中映射检查不代表游戏内体质效果验证。

本地对象分配对比固定为 24 个词条、80 万次汇总调用，使用同一 Java 21 和 JVM 参数，预热后读取线程累计分配量：

- 1.4.13：928,000,160 字节。
- 1.4.14：160 字节。
- 两版汇总校验值均为 `472000.0000005973`。

这是汇总方法在固定本地负载下的临时对象分配，不是整款游戏的内存、TPS、帧率或多人承载量测试。没有把 1.4.13 的服务端运行结果当成新版运行验证；客户端界面、网络和新版实际游戏表现本次未测试。
