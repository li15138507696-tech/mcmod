# 天命 1.4.19 通用版

本版面向 Minecraft 1.21.1 / NeoForge 21.1，客户端和服务端应使用同一通用版。使用 `/tianfu open` 打开界面；快捷键默认未绑定，可在按键设置里自行设置。界面只在当前没有其他界面或已经打开本界面时显示。

当前仅开放筋骨强健、身法轻捷、血气如林、力进如泉、拳如疾风、耸岳坚立六项独立属性天赋。原版的资质、体质、本体道痕、修炼、转世联动、随机命格、战斗效果和其他原有天赋暂不可用。旧版已经写入本体的数据不会自动撤销。

旧玩家首次进入时，通用版只读快照旧 `tianfu` 账本的点数；仅将已确认的六项安全天赋加入新账本。未确认选择和其他旧天赋保留在旧账本中，不自动生效或退款。旧账本及成交回执不会被通用版修改。未设置过难度、没有正点数且没有已购、确认、结算或回执记录的空账本按新玩家获得 8 点；已设置难度或已有上述记录的 0 点保留为 0，缺少难度但有正余额时保留余额。通用版余额与旧版余额之后各自独立，不双向同步；不要通过切换版本重复使用旧余额。

通用版不以本体 mixin、类、字段或 procedure 联动，未绑定本体版本；但无法保证未来 Minecraft、NeoForge 或未知模组组合的运行行为。此构建仅完成离线编译和规则测试，尚未进行实际游戏、服务器联机、死亡重生或转世验证。
