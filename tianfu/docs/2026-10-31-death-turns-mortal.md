# 死一次就变凡人 — 根因与修复（1.4.11）

> 2026-10-31

## 直接回答

**本体把「寿元 ≤ 0」或「修为 gamerule 关闭」当成转世，转世会把你整个人重置回凡人。**

反编译 `JingJieBaoCunProcedure`（死亡时由本体调用）：

```
202-216: 有 FUHUO 复活效果        → 跳过整段（不转世）
225-237: 修为 gamerule != true    → 走另一分支（1500）
291-296: shouyuan > 0             → 跳过整段（普通死亡，不转世）
299+   : 否则 —— 全清：
           669: zhuanshu = 1
           677: shouyuan = 100
           683: jieduan  = 0
           689: kongqiao = 0
           695/701: gushi_xiulian_jindu / dangqian = 0
           707: tizhi = 0                  ← 变凡人
           713: zuida_zhenyuan = 0
           后面还有 50 多个道痕/流派字段全部 = 0
```

**所以「死一次变凡人」= 你的 `shouyuan` 已经 ≤ 0（或世界关了修为 gamerule），这次死亡被本体判成了转世。**

## 寿元为什么会 ≤ 0

本体初始寿元只有 **100**，而 tianfu 的负向寿元天赋扣得比这多得多：

| 天赋 | 寿元变化 | 100 点基础寿元的结果 |
|---|---|---|
| `v2_shouyuan_kuwei` 寿元枯萎 | **−250** | 100 − 250 = **−150** → 必转世 |
| `v2_lifespan_scar` 命烛残尽 | **−400** | 被适配层夹到 **0** → 必转世 |
| `shouyuan_duancu` 寿元短促 | −100 | 100 − 100 = **0** → 必转世 |

也就是说：**只要买了一条这类负面天赋，之后死一次就归零重来。**
（正向的有 `shouyuan_ruhe` +200、`chuntian_yishou` +80、`shouyuan_mianchang` +50，但都抵不过 −250。）

这不是随机 bug，是数值与本体死亡判定的冲突——天赋描述只写了「寿元 −250」，没告诉你这等于「下次死亡直接转世」。

## 附带修掉的第二个问题：转世后体质回不来

即使不走转世，只要本体把 `tizhi` 清零过，就会卡死：

- 本体的清零写在 `PlayerVariables` 上；
- tianfu 的「已购 / 已结算」是**另一套 NBT**（`NeoForgeData/tianfu`），普通死亡不清；
- 于是 `settled` 还是 1，`applyAllConfirmed` 不会再跑 →
  **玩家明明买了十绝体，`tizhi` 却永远是 0，界面显示凡人、空窍加成全失效。**

### 修法：体质自愈

`TianfuEffects.healPhysique`，每 20 tick 检查一次：

```
已结算（settled=1）
 且 当前 tizhi == 0
 且 已购列表里能认出一条 BODY / SIJUE
 → 只补「体质身份」字段：
      tizhi = 该体质的档位
      十绝体/杀神：kongqiao==0 补 3、zuida_zhenyuan<=0 补 1000
      凡体：有 v2_apt_* 就按 KE1 口径补 kongqiao（甲2/乙1/丙5/丁8）
```

**绝不重跑结算**——道痕、上限、寿元都在结算时乘过，重跑会翻倍。

## 你该怎么做

1. 换上 `tianfu-1.4.11.jar`。
2. **如果你买过负向寿元天赋**，去 `/tianfu open` 看一眼「已购」。这类天赋现在会让「下一次死亡 = 转世」。
   要我把它改成「扣寿元但不致死（下限 1）」吗？—— 那样就不会再出现「死一次归零」，但等于削弱了这条负面天赋。
3. 已经变凡人的存档：1.4.11 会在 20 tick 内自动把体质补回来（前提是 tianfu 的已购记录还在）。
   如果连已购记录都被转世清空了，那就真的是新一世，需要重新买。
