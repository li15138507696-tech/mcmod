## 2. 点数经济（方案 ①）

- 基础点：`easy 顺天应命 8` / `normal 凡尘问道 6` / `hard 逆天争命 4` / `hell 万劫磨道 2`

- 品质成本：黄 1 / 玄 2 / 地 3 / 天 5 / 神 12 / 极 16 / 十绝体 16
- 理论最高点：8 + 24 = 32 → 买「极 16 + 十绝体 16」正好掏空，留余量必须降档
