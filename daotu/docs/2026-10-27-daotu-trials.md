# 道途试炼实现记录（1.7.0）

本版本在现有历练与锁定抽选循环中增加可接取的短期目标。

## 玩法

每五次已锁定抽选开放一个试炼节点，节点顺序领取，一次只能进行一个。M 界面显示当前进度，并在节点可用时提供三种选择：

- 百战试炼：最后一击击杀 8 只敌对 Monster。
- 行万里：接取后首次进入本世未探索的 2 个不同群系，接取前到过的不计。
- 静坐修炼：累计 180 秒潜行、静止且站在地面的时间。

完成奖励为当前抽选门槛的一半，写入既有历练池。完成状态、奖励标记与历练池在同一次 NBT 更新内保存，事件重放不会重复领奖。每世状态放在 daotu/run，转世时由现有 run 重置清除。试炼无期限，死亡和下线不清空进度。

## 边界

试炼只在服务端接取和累计进度；客户端只提交运行编号、节点与试炼类型。击杀事件继续沿用现有玩家最后一击钩子；探索与修炼复用每秒采样。达到抽选上限后不开放新试炼，完成既有试炼也不会突破上限。

没有新增物品、实体、贴图、配方或依赖；没有恢复已删除的宗门、流派树或觉醒玩法。

## 交付

- 版本：1.7.0
- 输出：build/libs/daotu-1.7.0.jar
- 编译：49 个 Java 源文件全部通过 JDK 21 编译。
- JAR：70 项资源与类，版本字段 1.7.0；已检查试炼类和网络包均在包内。

## 后续拓展建议

1. 丰富试炼目标：在现有三类之外加入首领挑战、采集和环境生存目标，再按转数提高目标层级。
2. 增加小幅天赋联动：为现有词条打上少量标签，凑成组合时给有上限的玩法效果，避免直接堆高属性。
3. 长线世界目标放在后续阶段：先确认本体可用的任务与势力接口，再考虑宗门事件或多人共同目标。
