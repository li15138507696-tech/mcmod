# daotu 1.5.2 — 蛊真人 9.8 适配

9.8 没有 `UikongqiaoguanbiProcedure`（10.x 才拆出来的收尾类），道途的收尾钩子原先注入它，
在 9.8 上既编译不过、运行也会缺类。

现在改为注入 `UikongqiaoquedingProcedure`：

- 9.8：它本身就是收尾结算；
- 10.x：它的实现是「先调 `guanbi.execute`、再 `closeContainer`」（javap 核对），TAIL 仍然在结算之后。

因此 **同一份 jar 同时兼容 9.8 与 10.x**。已用两个版本的本体各编译一次，均 exit 0。

产物 `daotu-1.5.2.jar`，已装进 9.8 服务端与 10.4 客户端整合包。游戏内未实测。
