# 天命界面重做规格（参考图布局）

> 参考图：三栏式卷册界面（左导航 / 中列表 / 右详情），深色底 + 金色描边 + 四角括号。
> 本文件是给编码阶段的**唯一视觉与结构依据**，所有坐标、颜色、字号以本文件为准。

## 0. 必须先修的 bug

游戏日志证据（`logs/latest.log`）：客户端连续 3 次打印
`[天赋] 客户端收到 K 键，请求天赋界面`，服务端**没有任何回应**，界面始终没打开，游戏随后正常退出（无崩溃）。

要求：
1. `TianfuRequestPayload.handle` 的整个服务端逻辑必须包在 `try/catch(Throwable)` 里，
   捕获后 `LOGGER.error("天赋请求失败", e)` 并**仍然**尝试发一次旧 `state`（哪怕 V2 快照发不出去），
   保证玩家至少能看到界面而不是毫无反应。
2. `TianfuV2Store.migrate` / `TianfuNet.sendAll` / `TianfuV2StatePayload.encode` 抛出的
   `IllegalStateException` / `IllegalArgumentException` 不得让整个 handler 静默死亡。
3. 客户端 `TianfuClientEvents` 在收到 K 键后，如果 200 tick 内没收到任何 S2C 状态，打印一次
   `[天赋] 等待服务端状态超时` 日志，便于下次定位。
4. 任何一条都不得改变既有方法签名。

## 1. 整体布局

1280×720 逻辑分辨率下的目标比例（按 GUI 缩放自适应，全部用相对坐标计算，禁止硬编码绝对像素）：

```
┌──────────────────────────────────────────────────────────────┐
│  天命录   所见未必为真，所得未必为福              [×]        │  顶部标题区 ~52px
│          见天地之变                                          │
├──────┬───────────────────────────┬───────────────────────────┤
│      │  [搜索框________] [筛选]  │  选中条目标题              │
│ 左导航│                           │  副标题 / 状态             │
│ 七页  │  ┌─────────────────────┐  │                           │
│      │  │ 条目 1              │  │  描述正文（自动换行）      │
│      │  │ 品质 · 成本 · 状态   │  │                           │
│      │  ├─────────────────────┤  │  效果明细（多行）          │
│      │  │ 条目 2（选中）       │  │                           │
```

- 外层：`#0E0F0C` 半透明底 + 1px 金色边框 `#8A7443`，四角各画一个 L 形括号（长 18px、粗 2px）。
- 左右分栏比例：左导航 **14%**、中列表 **38%**、右详情 **48%**（右详情占剩余全部）。
- 三栏之间各留 1px 竖分隔线 `#3A3628`。

## 2. 顶部标题区

| 元素 | 内容 | 样式 |
|---|---|---|
| 主标题 | `天命录` | 字号 ×2（`font.width` 用 2 倍缩放绘制），颜色 `#E8D9A8` |
| 副标题 | `所见未必为真，所得未必为福` | 1 倍字号，颜色 `#9A9078` |
| 第三行 | `见天地之变` | 1 倍字号，颜色 `#7A7158` |
| 关闭按钮 | 右上角 20×20 方框 + `×` | 边框 `#8A7443`，悬停时底色 `#3A3628` |

标题区下方画一条 1px 横线 `#3A3628`，从左边框到右边框。

## 3. 左导航（七页）

- 每页一个按钮：宽 = 导航栏宽 − 16，高 **34px**，纵向间距 8px，从标题线下方 12px 开始。
- 未选中：底色 `#171814`、边框 `#2E2A20`、文字 `#9A9078`。
- 选中：底色 `#242018`、边框 `#8A7443`（1px）、文字 `#E8D9A8`，并在左侧画 2px 金色竖条。
- 悬停：底色 `#1F1D16`。
- 顺序固定：难度 / 出身 / 资质 / 流派 / 体质 / 心智 / 气运。
- 导航底部（距底 12px）竖排两行小字 `有据`、`而后知`，颜色 `#5E5744`，字号 1 倍。

## 4. 中列表

**搜索行**（列表顶部，高 20px）：
- 输入框：宽 = 列表宽 − 56，高 20px，底色 `#171814`，边框 `#2E2A20`，
  占位文字 `查阅此卷…`（颜色 `#5E5744`），输入文字 `#D8CBA8`。
- 右侧按钮：宽 48px，高 20px，文字 `筛选`（点击切换"仅显示已购"，开启时边框变金色）。

**列表项**（可滚动区）：
- 每项高 **38px**（两行：标题 + 元信息），条目间 1px 分隔线 `#2A261C`。
- 标题行：1 倍字号，颜色 `#D8CBA8`；已购条目在标题右侧画一个小金色方块（4×4）。
- 元信息行：`品质 · 成本 · 状态`，颜色 `#7A7158`；成本为负显示 `补点 +N`（金色 `#C9A961`）。
- 选中项：底色 `#242018`，左侧 3px 金色竖条，标题色 `#F0E4C0`。
- 悬停项：底色 `#1F1D16`。
- 空列表：居中显示 `此页暂无条目`（颜色 `#5E5744`）。

**滚动条**：列表右缘，宽 3px，轨道 `#1A1712`，滑块 `#8A7443`；支持滚轮与拖拽。

## 5. 右详情

- 标题：选中条目名，2 倍字号，`#E8D9A8`；未选中时显示 `未择条目`（`#5E5744`）。
- 副标题：`品质 · 成本 · 已购/可购/锁定`，1 倍字号，`#9A9078`。
- 描述正文：1 倍字号，`#B8AC8C`，宽度 = 详情栏宽，**按字符宽度自动换行**，行距 10px。
- 效果明细：每条效果一行，前缀 `· `，颜色 `#9A9078`。
- 底部按钮区（距详情栏底 16px，右对齐）：
  - `购买`：可用时边框金、文字 `#E8D9A8`；不可用时文字 `#5E5744` 且不响应点击。
  - `撤销`：已购且可撤销时显示。
  - 按钮尺寸 64×20，间距 8px。
- 不可购买原因（若有）：在按钮上方 1 行，颜色 `#A85A4A`（红褐）。

## 6. 底部状态栏

- 左：`{当前页条目数} 条记载 / {页名}`，颜色 `#7A7158`。
- 右：`滚轮翻阅 / 空格购买 / Esc 合卷`，颜色 `#5E5744`。
- 顶部 1px 分隔线 `#3A3628`。

## 7. 交互

| 输入 | 行为 |
|---|---|
| 滚轮 | 中列表滚动；详情栏内容超高时滚详情 |
| 左键点击导航 | 切页，**保留每页各自的滚动偏移与选中项** |
| 左键点击列表项 | 选中并刷新右侧详情 |
| 空格 | 购买当前选中项（等价点击购买） |
| Ctrl+F | 聚焦搜索框 |
| Esc | 搜索框聚焦时先清空搜索，否则关闭界面 |
| 右键 | 无动作（不得误触购买） |

- 已确认（`confirmed`）后整页只读：购买/撤销按钮全部禁用，导航仍可切页。
- 任何购买/撤销都必须走既有 payload（`TianfuBuyPayload` / `TianfuRevokePayload`），
  **客户端不得自行扣点**，余额只以服务端快照为准。

## 8. 硬约束

1. 不新增第三方依赖；只用 Minecraft 原生 `GuiGraphics` / `Font` 绘制。
2. 不引用任何服务端类到客户端以外；`TianfuViewScreen` 只在客户端加载。
3. 现有方法签名（含 7 参数构造器、`refresh`、`refreshV2`）保持不变。
4. Java 源文件 UTF-8 无 BOM。
5. 颜色一律走本文件的常量表，集中在类顶部定义，便于后续换肤。
6. 中文文案必须完整，不得出现乱码或 `\uXXXX` 字面量。
